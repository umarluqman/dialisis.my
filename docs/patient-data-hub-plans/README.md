# Patient Data Hub Plans

Use these documents as the working set for the combined `dialysis.my` strategy:

- patient-first dialysis intake/transfer data hub
- center-paid subscription product (after pilot proof)
- neutral trust positioning using `Verified` (not `Pilihan Utama`)

## Current focus

- Build a useful workflow for patients, nurses, and doctors.
- Reduce manual data collection and re-entry.
- Prove operational value with pilot centers before pricing/package decisions.
- Keep the original business goal (help centers fill chairs) but reach it through patient problem-solving first.
